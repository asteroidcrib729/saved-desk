## Cleanup and evidence retention

Cleanup is confined to verified disposable test fixtures inside the project's ignored `.cache/` directory. Synthetic profiles, catalog/sidecars, sessions, downloads and duplicate test executables can be removed after their processes exit. Reports, logs, screenshots and source test scripts are retained. Owner accounts, media and installed application data are outside cleanup scope. Dependency caches, signed runtime build input, current target binaries, immutable release review assets, rejected candidate evidence and quarantined historical installers are retained.

Completed cleanup removed **32,398 files / 3.05 GiB** from **191 inactive isolated runs**, plus generated benchmark media. **478 evidence files** retained their SHA-256 hashes. **22 test-created junctions** were detached without traversing their targets, including links retaining the former project name. Synthetic session/catalog/browser data and redundant test executable copies were removed.

The local cleanup record is `.cache/residual-cleanup-0.2.7.json`. The source/ignore/Markdown audit is `.cache/git-readiness-audit.json`; post-cleanup artifact verification is `.cache/documentation-cleanup-audit-0.2.7.json`.

Historical release directories remain immutable. Final review assets must contain the exact current installer and corresponding source/notices, hashes and acceptance boundaries. A later documentation update does not turn an earlier installer into a tested current artifact.
