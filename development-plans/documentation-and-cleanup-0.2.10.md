## Guarded residual cleanup

Cleanup removed **2,744 files / 167,728,358 bytes (about 160 MiB)** from **89 reviewed inactive fixture targets** under the ignored project .cache directory.

The selected UUID fixture families were native-authentication, native-oauth-configuration, native-external-tools, native-live, native-platforms, native-smoke, native-watch-later and host-acceptance. Only synthetic downloaded media, catalogs/sidecars, DPAPI fixtures, WebView profiles, temporary Firefox/selected-tool fixtures and leftover test-installation/profile directories were eligible.

The PowerShell guard checked resolved paths remained inside the project cache, refused active app/cache test processes, refused any reparse point before recursion, and required owner_data_restored in host reports before selecting host payloads. Unknown paths were not broadly deleted. No test-created junction required detachment in this pass.

**57 retained run evidence files** were checksum-verified unchanged. Reports, logs, screenshots, synthetic failure evidence and reproducible test source remain. Historical evidence records may still name removed disposable payload paths; regenerate those payloads by rerunning the relevant source harness when needed.

Owner media, application data, account grants and local provider registration files were outside the deletion scope. Current builds, external tools, dependency caches, offline-runtime build input, immutable release sets, quarantined old installers and rejected-candidate records were retained. This cleanup is not an uninstall or a wipe of personal downloaded content.
